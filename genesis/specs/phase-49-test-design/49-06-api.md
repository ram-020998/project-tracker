# 49-06 — HTTP API

> **Status:** SPEC-DRAFTED 2026-10-26. Repo: **genesis** (backend). Parent: `specs/phase-49-test-design.md`.
> The single home of the phase's HTTP contract. Routes are thin over 49-02 (store), 49-04 (stage services) and 49-05
> (impact). Under `/api` (ADR-028); plain `def` handlers; JSON errors `{detail}`.

## 1. Module + registration

New `genesis/genesis/api/testdesign.py` → `register_testdesign_routes(api, settings, kb_store, run_manager, …)`,
registered in `genesis/genesis/api/app.py` like `register_object_wiki_routes`. The generic stage routes in
`features.py` (`GET /features/{id}/stages/{stage}`, actions, `export.md`) already serve `test_design` once it is in
`VALID_STAGES` (49-04 §2). Status codes: 404 unknown feature/record; 409 lifecycle/state conflicts (message from the
service) and CAS conflicts (`StaleWriteError`, the house rule); 422 malformed payload/artifact.

Added after the 49-05 build (49-05 As built):
- `ImpactNotFoundError` → **404**, `ImpactConflictError` → **409** (`genesis/genesis/services/testimpact.py:53-57`).
- **On-demand resolution (R8):** `GET /features/{id}/test-suite`, `GET /test-cases/{cid}` and
  `POST /applications/{app}/test-impact` call `TestImpactService.resolve_unresolved(app_uuid)` (`testimpact.py:332`,
  idempotent) before reading, so recovery is never startup-only. This also covers KB rows that arrive through a Hub
  KB pull, so no separate pull trigger is added. Run it off the event loop (the handlers are plain `def`).
- The impact result carries fields beyond the 49-05 §5 shape: `hop` on each suite, `object_removed` on each case and on
  each `via` path entry. Keep them in the response and in the contract fixture the web types mirror (L-011).
- A sync for the sync source must have `kb_syncs.status = 'succeeded'`; the syncs picker lists only those.

## 3. Suite, top-ups, export

| Method + path | Body | Response | Errors |
|---|---|---|---|
| `GET /features/{id}/test-suite` | — | `SuiteTree` = `{suite, scenarios:[ScenarioDto], cases:[CaseDto], coverage}`; `suite: null` before Finalize | 404 feature |
| `GET /features/{id}/test-suite/export.csv` | — | `text/csv` attachment (49-04 §7) | 409 not finalized |
| `POST /features/{id}/test-suite/topups` | `{story_ids: [int], notes?}` | `{topup, run_id}` | 409 not finalized / a top-up running / prereq; 422 empty or foreign story ids |
| `GET /features/{id}/test-suite/topups/latest` | — | `{topup: TopupDto \| null}` (proposals parsed) | — |
| `POST /test-topups/{tid}/apply` | `{accepted: [ref]}` | `{suite: SuiteTree, applied: [ref], rejected: [{ref, reason}]}` | 409 not `ready` |
| `POST /test-topups/{tid}/discard` | — | `{topup}` | 409 not `ready` |

`coverage` = `{stories: [{story_id, key, title, story_type, cases: int, needs_review: int, state:
covered|uncovered|task}], uncovered: int, needs_review: int}` (`task` = D14 "covered through objects or scenarios").

## 4. Test cases and scenarios

| Method + path | Body | Response | Errors |
|---|---|---|---|
| `GET /test-cases/{cid}` | — | `{case: CaseDto, feature: {id, name, app_uuid}}` | 404 |
| `POST /features/{id}/test-cases` | `{title, gherkin, type, priority, story_ids?}` | `{case}` (Draft, new `TC-`) | 409 not finalized; 422 |
| `PATCH /test-cases/{cid}` | fields + `row_version` | `{case}` | 409 stale; 422 |
| `POST /test-cases/{cid}/transition` | `{action: approve\|retire\|restore}` | `{case}` | 409 refused (message names blocking scenarios) |
| `DELETE /test-cases/{cid}` | — | 204 | 409 not Draft / referenced |
| `PUT /test-cases/{cid}/stories` | `{story_ids}` | `{case}` | 422 foreign story |
| `POST /test-cases/{cid}/objects` | `{uuid?, name, type}` | `{case}` (resolved per 49-05 §2, origin `manual`) | 422 |
| `DELETE /test-cases/{cid}/objects/{link_id}` | — | `{case}` | 404 |
| `POST /test-cases/{cid}/mark-reviewed` | — | `{case}` (F7) | — |
| `GET /test-scenarios/{sid}` | — | `{scenario: ScenarioDto, cases: [CaseDto], objects: [derived], feature}` | 404 |
| `POST /features/{id}/test-scenarios` | `{title, description, case_ids?}` | `{scenario}` (Draft, new `TS-`) | 409 / 422 |
| `PATCH /test-scenarios/{sid}` | fields + `row_version` | `{scenario}` | 409 stale |
| `PUT /test-scenarios/{sid}/steps` | `{case_ids: [int], row_version}` | `{scenario}` | 409 stale; 422 cross-suite/retired |
| `POST /test-scenarios/{sid}/transition` | `{action}` | `{scenario}` | 409 |
| `DELETE /test-scenarios/{sid}` | — | 204 | 409 not Draft |

`CaseDto` / `ScenarioDto` = 49-02 §3 `case_dto` (+ `row_version`) / scenario columns + `steps: [{position, case_id,
case_key, case_title, case_status}]`. **One builder per DTO** used by every route (L-039).
