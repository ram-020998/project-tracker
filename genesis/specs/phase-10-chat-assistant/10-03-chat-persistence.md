# 10-03 — Chat persistence (migration + stores)

**Repo:** `genesis` · **Ships with:** v0.19.0 · **Depends on:** — · **Blocks:** 10-04

## 1. Objective

Durably persist chat sessions and their transcripts so a user can leave and return, and can delete
sessions. Add the second-ever migration (`m0002`) and two repositories in the existing
`genesis/db/` + repository style.

## 2. Current state (verified)

- `genesis/db/database.py` `Database` — connection factory; `PRAGMA foreign_keys=ON` is set on every
  connection, so FK cascade works. `tx()` = transactional context.
- `genesis/db/runner.py` — forward-only runner; `Migration(version, name, up)`; versions must be
  **contiguous from 1**; `migrate(db, MIGRATIONS)` idempotent per startup.
- `genesis/db/migrations/m0001_baseline.py` — version 1 (`runs` + `run_events`). Registered in
  `genesis/db/__init__.py`'s `MIGRATIONS` list (verify the exact registration point when
  implementing). **Next version = 2.**
- Repository pattern: `RunStore`/`EventLog` receive a `Database` (or a path), never open ad-hoc
  connections, never create tables. Dataclass records with `_from_row`.

## 3. Design

### 3.1 Migration `m0002_chat`

`genesis/db/migrations/m0002_chat.py`:

```python
def _up(conn):
    conn.execute("""
        CREATE TABLE IF NOT EXISTS chat_sessions (
            id         TEXT PRIMARY KEY,
            title      TEXT NOT NULL DEFAULT 'New chat',
            created_at TEXT NOT NULL,
            updated_at TEXT NOT NULL
        )
    """)
    conn.execute("""
        CREATE TABLE IF NOT EXISTS chat_messages (
            seq        INTEGER PRIMARY KEY AUTOINCREMENT,
            session_id TEXT NOT NULL REFERENCES chat_sessions(id) ON DELETE CASCADE,
            role       TEXT NOT NULL,
            content    TEXT NOT NULL,
            events     TEXT NOT NULL DEFAULT '[]',
            ts         TEXT NOT NULL
        )
    """)
    conn.execute("CREATE INDEX IF NOT EXISTS ix_chat_messages_session ON chat_messages(session_id, seq)")

chat = Migration(version=2, name="chat", up=_up)
```

Register `chat` in the `MIGRATIONS` list after `baseline`.

### 3.2 Repositories `genesis/chat/store.py`

```python
@dataclass
class ChatSessionRecord:
    id: str; title: str; created_at: str; updated_at: str
    message_count: int = 0   # populated by list()/get() via a COUNT join; not a column

@dataclass
class ChatMessageRecord:
    seq: int; session_id: str; role: str; content: str; events: list; ts: str

class ChatStore:            # sessions
    create(rec) ; get(id) -> ChatSessionRecord|None
    list(limit=100) -> [ChatSessionRecord]     # ORDER BY updated_at DESC, with message_count
    rename(id, title) ; touch(id)              # bump updated_at
    delete(id) -> bool                         # FK cascade removes messages

class ChatMessageStore:     # messages
    append(session_id, role, content, events=None) -> int   # returns seq; bumps session.updated_at
    list(session_id, after_seq=0, limit=1000) -> [ChatMessageRecord]
    count(session_id) -> int
    purge(session_id) -> int                   # explicit, though delete() cascades
```

Both take a `Database` (mirror `RunStore`). `events` is JSON-encoded on write / decoded on read.
`append` and `rename` also `touch` the session's `updated_at` (so the list orders by recency).

### 3.3 IDs

`c-<uuid4().hex[:12]>` (mirror `_new_run_id`), generated by the caller (ChatManager), not the store.

## 5. Tests / DoD

- `migrate` applies v2 on a fresh db and is a no-op on re-run; `current_version()==2`; contiguity
  guard still passes with two migrations.
- CRUD round-trips: create/get/list (with `message_count` + recency order), append/list messages
  (events JSON round-trips), rename/touch bumps `updated_at`.
- **FK cascade:** `delete(session)` removes its messages (assert `count()==0` after).
- pytest + ruff green; existing `test_migrations`/db tests unaffected.

## 6. Risks

- If `genesis.db` predates FK enforcement for some rows — not applicable (fresh tables). `mode=ro`
  readers (10-02) are unaffected by these writes.
- Keep `events` blobs bounded (store folded thoughts/tool summaries, not raw bulk) to honor ADR-010.
