Workflow: Agent prompt (agent-prompt) — Answer a prompt with one agent turn (optionally as a custom agent) and write the answer to output.md.
Inputs: prompt=Print hello world as a plain text along with the date and timestamp
Steps: run_agent — One agent turn: the custom agent's instructions and the prompt, with the effective skills and read-only MCP servers (re-checked against the read-only rule first); writes the answer to out…; validate_output — output.md exists, is not empty and is UTF-8 text.; finish — End the run; the answer is output.md in the run's documents.; escalate — After 3 refused attempts: approve or give feedback to run the agent again (feedback goes into its prompt), reject to end the run as failed.; retry_agent — Reset the attempt count and run the agent again.; give_up — End the run as failed.
