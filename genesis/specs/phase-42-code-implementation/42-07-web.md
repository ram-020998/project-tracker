# 42-07 — Web (drag-into-Implementation + the read-only review surface)

> **Status:** 🟡 DRAFTED. Repo: **genesis** (`web/`). Mirrors the Phase-34 board drag + card states. Parent: `specs/phase-42-code-implementation.md`.

## 1. Drag confirm

- `BoardPage.onDragEnd` special-cases a card **entering the `implementation` lane** (from any lane) → open **`StartImplementationDialog`** instead of persisting: *"Start the automated implementation for this ticket? All object changes in the design will be applied to the dev environment. This cannot be undone automatically (a rollback document is prepared)."* **Yes** → `POST …/cards/{story_id}/implementation/start`; **No** → the normal lane persist (move without a run). A card with a running implementation is **locked** (non-draggable).

## 2. Card states (`StoryCard`/`StoryCardFace` + `lanes.ts`)

- Running → an "Implementation running" indicator + a `Link` to `/runs/{implementation_run_id}` (from the card DTO, 42-05).
- Failed → **light-red** card + "Workflow failed" + the run link (draggable again — re-dragging into Implementation re-runs).
- Escalated (reverify gate awaiting) → the standard awaiting-input treatment + a link to the run's gate (the user picks proceed / send-back in the run detail HITL surface).

## 3. The read-only review surface

- A card in **Implementation** or **Code Review** opens (a drawer, or a routed `/workbench/:appUuid/cards/:storyId/implementation` page) a **read-only** view rendering `GET …/implementation/report`:
  - the **implementation report** (objects created / updated / deprecated, each with type + new version + verify result),
  - the **rollback document** (`rollback.md`, rendered read-only),
  - basic run info (run id + link, status, timing, credits).
  - **No editing, no chat, no Lavish** — this is an inspection surface. (Contrast the Design Review workspace, which is an editable chat + annotatable preview.)

## 4. Plumbing

- `lib/api/workbench.ts` (`startImplementation`, `implementationReport`), `hooks.ts` (`useStartImplementation`, `useImplementationReport`), `types/workbench.ts` (card DTO gains `implementation_run_id`/`implementation_run_status`/`implementation_story_stage_id`; `isImplementationRunning`/`isImplementationFailed`), `lib/query/keys.ts`. Route + breadcrumbs if a routed page is chosen.
- jest-axe on `StartImplementationDialog` + the review surface. `npm run build` + **commit `web/static`** (the stale-bundle guard).

## 5. Out of scope

A wiki browsing UI; editing the implementation result; a Code-Review-lane workspace.
