# 52-13 — HTTP API: the per-launch token, Origin/Host checks and new routes

> **Status:** SPEC-DRAFTED 2026-11-18. Repo: **genesis** (`genesis/api/**`, `genesis/testexec/reports_origin.py`).

> 52-08, 52-10, 52-12.

## 1. Rules

- **Token (D14):** generated per stack start inside the app container (32 random bytes, base64url), written to the
  state volume (0600) for `genesis-launcher token`; the SPA receives it in the URL fragment, keeps it in session
  storage, removes it from the address bar and sends `Authorization: Bearer <token>` on every `/api` call, added in the
  one central client (ADR-028). Server: middleware refuses every `/api` request without a valid token (401), except
  `GET /api/config/health` and the static SPA files; constant-time compare.
- **Origin and Host:** every request's `Host` must be `127.0.0.1:<port>` or `localhost:<port>`; state-changing methods
  need an `Origin` equal to the app origin (or absent only for token-bearing non-browser clients); 403 otherwise.
- **Report origin (ADR-085):** the same token as a short-lived signed cookie or query token issued by the app for the
  report link; Host-checked as today.
- **SSE and WebSockets:** the token is accepted as a query parameter only on the event-stream routes (EventSource
  cannot set headers), scoped and checked the same way.
- **Copilot control header** (`run_routes.py`): moves onto the token; the separate header goes.

## 2. New and changed routes (contract table)

| Route | Purpose |
|---|---|
| `GET /api/agent-runtime/status` | Environment (provider, VM state, versions), controller state (`ready` · `refusing` with reason), image digests, last self-test result and time, queue length, live sandboxes |
| `POST /api/agent-runtime/self-test` | Run the self-test now |
| `GET /api/agent-runtime/egress` · `PUT …/egress` | Base hosts (read-only), user additions (edit, logged) |
| `GET /api/runs/{id}/sandboxes` | Per-turn sandbox telemetry from the event log (52-03 §3), paged |
| `GET /api/runs/{id}/egress` | Egress decisions and drop counts for the run |
| `GET /api/backups` · `POST /api/backups` · `GET /api/backups/{id}` | List, create, status and verify result (restore stays a launcher command: it stops the stack) |
| `GET /api/testing/recordings/{id}/display` | The noVNC proxy for a live recording (52-10), WebSocket |
| `POST /api/config/kiro/login` (changed) | Starts Genesis's own device-code sign-in (52-08) |

Shapes mirrored in `web/src/types` with golden fixtures; a contract drift fails a test (L-011, L-109).

## 3. Tests

Middleware: missing, wrong and valid tokens; health and static exemptions; Host and Origin matrix; SSE query token;
the report origin's token; a request from another origin refused (CSRF). Route tests for each row; contract fixtures;
the CLI and acceptance drivers updated to send the token (`genesis-launcher token`); route-order check (L-096).
