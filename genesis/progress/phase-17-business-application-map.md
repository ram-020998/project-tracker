## First live generation (2026-08-07)

Ran against **"AS GSS Full Application"** (2,763 objects; `source_sync_id=5`). The agent produced a genuinely
high-quality, business-language model — **no technical vocabulary**:

- **Domain:** "Procurement source selection and proposal evaluation."
- **10 capabilities** (Evaluation Setup & Lifecycle, Vendor & Proposal Mgmt, Criteria & Weighting, Evaluator Teams,
  Proposal Scoring, Consensus & Award, Task Coordination, Document Mgmt, AI-Assisted Evaluation, Audit/Compliance).
- **10 entities, 5 actors, 14 capability relations.**
- A **14-stage value stream** ("Solicitation Ready → Set Up → Define Criteria → Register Vendors → Assign Team →
  Launch/AI Insights → Score → *Review (accepted / rejected→rework)* → Reconcile Consensus → *Signatures required?* →
  Collect Signatures → Produce Signed Award Recommendation → Close Out → Finalized").
- **6.07 credits**; **coverage 0.355** (< the 0.6 gate → correctly routed to the **review** gate, human-approved).

**Data acceptance: PASS.** The remaining 17-06 work is metric tuning + a friendly error, not model quality.

   Captured as two `AGENT_ONBOARDING.md` §7 lessons.

## Key decisions / notes
- **Agent input = the evidence pack only** (no MCP on the synthesis nodes) — self-contained + stronger anti-hallucination
  (evidence integrity = referenced uuids ⊆ pack). Scoped in 17-03.
- **Two gates**: `escalate` (validator exhaustion) + `review` (coverage-low OR explicit review request).
- **Code-free** throughout (ADR-037); **KB-only** (no environment call); the only mutation is the local business-map
  upsert (async via `asyncio.to_thread`, 16-03 lesson).
