## Method changes
PROCESS findings from a review are recorded here (with the review that raised
them) and adopted **before** the next unit starts (umbrella §6.4).

- **2026-10-19 — 47-01 established the method artifacts.** Inventory
  (`inventory.csv` + `scripts/inventory.py`), area taxonomy (`areas.yaml` +
  `scripts/check_areas.py`), the five schemas (`schemas/` +
  `scripts/validate_schemas.py`), the three templates (`templates/`), and the
  batch plan (`batches.yaml` + `scripts/plan_batches.py` + `scripts/check_batches.py`).
  Decisions recorded for later passes:
  - `inventory.py` excludes `genesis/migration/**` — the migration workspace is
    not a migration *source*; row count is measured against the base tag.
  - Area globs are **repo-prefixed** (`<repo>/<path>`); overlap is allowed and a
    unit's `primary_area` disambiguates. 950 code files map with 0 unmatched;
    74 are declared exceptions (70 `web/static/**` generated SPA, 4 vendored Lavish SDK).
  - Oversized sources are split only at **safe boundaries** (a blank line outside
    a code fence, or a heading) so no paragraph/table/code block is cut.
- **2026-10-19 — 47-01 gate: approved with changes 1–3** (see `handoffs/47-01.md`).
  - **Pilot** recomposed: P1 = phases 35/37/38 + the ADR-065 toggle note + carved
    ranges of `decision-log` (1323–1353), `bible/04` (70/72/73) and `bible/06`
    (the collaboration lessons: 334, 336, 341, 347, 349, 351, 353–354); P2 = all
    of phase 36. Carves are removed from the B batches (complements tile the rest).
  - **Batch cap 250,000 → 200,000 chars**; re-planned to 28 batches (was 22),
    max batch 199,721.
  - **Areas:** `platform-runtime` → `engine` + `runs-config`; `appian-parser`
    split out of `appian-kb`. Now 14 real areas + `all`/`history`; schema enums
    updated; coverage re-checked green (0 unmatched).
