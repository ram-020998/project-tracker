What Makes It Intelligent

🗺️

Schema from Atlas KB

Queries table structures, FK relationships, and field mappings from the parsed application knowledge base — no manual configuration needed.

🔍

Learns from Existing Data

Finds a real record in the target status and studies its complete data footprint — then generates new data matching the same pattern.

🔗

Understands Relationships

Knows which child tables need records, resolves FK chains automatically, and creates parent + children atomically in one call.

📊

Live Reference Data

Queries valid status codes, methods, and lookup values directly from the environment — never uses stale or hardcoded values.

🧠

Workflow-Aware

Reads process models and business rules from Atlas to understand what data should exist at each application state.

✅

Self-Validating

Verifies field coverage against the live schema. Ensures ≥80% of writable fields are populated with documented reasoning.
