# Guide: Appian Documentation

Search official Appian platform documentation for any topic.

## When to use
- "How does Appian handle record types?"
- "What's the best practice for process models?"
- "Find Appian docs on SAIL expressions"
- Any question about Appian platform capabilities (not specific to the PO's application)

## Note
This guide requires the **appian-docs** MCP server to be configured in `mcp.json`. If it's not available, let the PO know and suggest they check the Appian documentation website directly at https://docs.appian.com.

## How to use
If the appian-docs MCP is configured:
- `search_appian_knowledge_sources(query)` → search official docs

If not configured, suggest:
- "I don't have access to Appian docs search. You can check https://docs.appian.com for [topic]."

## Guidelines
- Use this for **platform** questions, not application-specific questions
- For application-specific questions, use Atlas tools instead
- Summarize doc results in plain language for the PO
- Link to specific doc pages when available
